What this level does

Level 1 assumes you have never written a prompt before. It gives you one frame to write every request with, then applies that frame to the four jobs you already do every week.

One frame for every request

Role, Context, Task, Format. Four questions that turn a vague instruction into a request the AI can actually carry out.

Applied to real teaching work

Sessions 2 to 4 use the same frame for lesson plans, exams and marking — the tasks that take the most of your week.

You stay the teacher

The AI drafts; you check. Nothing produced here goes to a class before a qualified teacher has read it and corrected it.
